# 本地演示指南

## 演示目标

在 3–5 分钟里展示：经营数据观察 → Agent 分析与证据 → 运营事件处理 → 人工审批 → 模拟履约与恢复。

## 主系统

按 README 启动 `http://localhost:8080`（或使用独立端口 `18080`），依次打开“决策总览”“Agent 工作台”和“运营处置中心”。

未配置模型 API 时，不声称 Agent 已真实完成调用；可说明工具与只读查询设计，并展示离线业务与测试。

## 独立三场景

按 README 的命令生成新演示状态并启动 `http://localhost:8081`，进入“运营处置中心”：

1. **正常解决：** 检查订单、异常、人工审批、库存预留、模拟履约及最终关闭结果。
2. **审批拒绝：** 拒绝后检查业务状态与库存不被越权修改。
3. **中断恢复：** 由既有模拟发运回执恢复工作流，验证重复执行没有产生二次发运。

需执行写入操作时，在页面填写本次终端生成的 `EIA_DEMO_WRITE_TOKEN`。**不要在演示视频、截图或仓库中暴露令牌。**

## 截图与录屏

仅采用真实浏览器中的最新页面；隐藏任何模型密钥、令牌、私人路径和本地日志。可展示系统边界及合成数据声明，不要将模拟结果包装成实际企业经营成效。
